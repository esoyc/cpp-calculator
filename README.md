# C++ Terminal Calculator

A simple, robust interactive command-line calculator written in C++. 

## Features
- Basic arithmetic operations: Addition, Subtraction, Multiplication, Division, Modulo.
- Input validation for invalid menu selections.
- Zero-division and Modulo-by-Zero error handling (prevents program crashes).
- Continuous operation loop until explicit exit.

## How to Run
```bash
# Compile
g++ -o calculator main.cpp

# Run
./calculator
